## Authentication

All API endpoints are authenticated using Bearer tokens and picked up from the specification file.

<RequestExample>

```shellscript Auth
curl --location 'https://zeus.ask-wire.com/auth/otp/login' \
--form 'username=""' \
--form 'password=""'
```

</RequestExample>

```json
{
  "access_token": "",
  "token_type": "bearer"
}
```
