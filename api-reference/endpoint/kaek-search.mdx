title: "Search a parcel by KAEK"
description: "Search for a parcel using its KAEK (cadastral) code."
openapi: "GET /api/geocoding/kaek-search/"
---

## Overview

Returns parcel information for a given KAEK (cadastral) code, including the parcel area and geometry.

Requires a valid Bearer token in the `Authorization` header. See [Authentication](/api-reference/endpoint/authentication) to get one.

---

## Query parameters

| Parameter   | Type   | Required | Description                |
| ----------- | ------ | -------- | -------------------------- |
| `kaek_code` | string | Yes      | KAEK number to search for. |

---

## Response fields

| Field      | Type   | Description                                |
| ---------- | ------ | ------------------------------------------ |
| `kaek`     | string | The KAEK code.                             |
| `area`     | number | Parcel area.                               |
| `geometry` | string | Parcel geometry as a GeoJSON string.        |

---

## Example request

```bash
curl -X GET "https://pandora.ask-wire.com/api/geocoding/kaek-search/?kaek_code=051207908001" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
