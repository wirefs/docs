## Overview

Returns geocoding information for a given address — coordinates, match type, and a normalized address string. Optionally fetches KAEK (cadastral parcel) information alongside the geocoding result.

Requires a valid Bearer token in the `Authorization` header. See [Authentication](/api-reference/endpoint/authentication) to get one.

---

## Query parameters

| Parameter | Type    | Required | Description                             |
| --------- | ------- | -------- | --------------------------------------- |
| `address` | string  | Yes      | Address to geocode. Max 255 characters. |
| `kaek`    | boolean | No       | Also fetch KAEK (parcel) information.   |

---

## Response fields

| Field               | Type   | Description                          |
| ------------------- | ------ | ------------------------------------ |
| `latitude`          | number | Latitude of the matched location.    |
| `longitude`         | number | Longitude of the matched location.   |
| `location_type`     | string | Type of the match (e.g. `ROOFTOP`).  |
| `formatted_address` | string | Normalized/formatted address string. |
| `kaek`              | string | KAEK (parcel) code. Only populated when `kaek=true` and a parcel matches. Otherwise `null`. |

---

## Example request

```bash
curl -X GET "https://pandora.ask-wire.com/api/geocoding/geocode/?address=Panepistimiou%2030%2C%20Athens&kaek=true" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Example response

```json
{
  "latitude": 37.9807567,
  "longitude": 23.7337138,
  "location_type": "ROOFTOP",
  "formatted_address": "Panepistimiou 30, Athina 106 79, Greece",
  "kaek": null
}
```
