---
title: "Query layer properties"
description: "Retrieve properties from geographic and environmental layers for a given location."
openapi: "GET /api/layer-properties/"
---

## Overview

Returns properties from a broader set of geographic and environmental layers for a given coordinate, including town-planning building blocks, floods, seismic zones, and wildfire risk.

Requires a valid Bearer token in the `Authorization` header. See [Authentication](/api-reference/endpoint/authentication) to get one.

---

## Query parameters

| Parameter   | Type   | Required | Description                                                                                         |
| ----------- | ------ | -------- | --------------------------------------------------------------------------------------------------- |
| `latitude`  | number | Yes      | Latitude of the location.                                                                           |
| `longitude` | number | Yes      | Longitude of the location.                                                                          |
| `layer`     | string | Yes      | Layer type. One of: `building_blocks`, `country`, `floods`, `parcels`, `seismic_zones`, `wildfire`. |

---

## Response

Returns a JSON object with layer-specific data for the given location. The shape varies by layer. See the examples below for each layer.

If the layer has no data at the location, the response is an empty object (`{}`).

---

## Examples

### Building blocks layer

```bash
curl -X GET "https://pandora.ask-wire.com/api/layer-properties/?latitude=37.9807567&longitude=23.7337138&layer=building_blocks" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

  "valid": "23/11/1948",

  "landuse": "Green areas & / or sports facilities",
  "fek_file": "http://epoleodomia.terra.gr/FEK/060249FT000313XXA-1948.pdf",
