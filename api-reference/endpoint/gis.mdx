---
title: "Query GIS layer properties"
description: "Query a GIS layer at a given latitude/longitude and return the layer-specific properties."
openapi: "GET /api/gis/"
---

## Overview

Queries the Greece parcels worker for a given GIS layer at a latitude/longitude coordinate and returns the layer-specific properties. The response shape varies by layer.

Requires a valid Bearer token in the `Authorization` header. See [Authentication](/api-reference/endpoint/authentication) to get one.

---

## Query parameters

| Parameter   | Type   | Required | Description                                        |
| ----------- | ------ | -------- | -------------------------------------------------- |
| `latitude`  | number | Yes      | Latitude of the location.                          |
| `longitude` | number | Yes      | Longitude of the location.                         |
| `layer`     | string | Yes      | GIS layer type. One of: `apaa`, `crime`, `parcel`. |

---

## Response

Returns a JSON object with layer-specific properties. The exact shape varies depending on the `layer` value requested.

| Status | Description                                             |
| ------ | ------------------------------------------------------- |
| `200`  | Layer-specific properties for the given location.       |
| `400`  | Invalid or missing `latitude`, `longitude`, or `layer`. |
| `404`  | No GIS data found for this location.                    |
| `500`  | Error connecting to the GIS API.                        |

---

## Crime layer fields

The `crime` layer returns crime counts for the regional unit that contains the location, not for the exact point. Nearby coordinates in the same regional unit return the same figures.

Each category has one field per year (for example, `OT_2025`) and a total for 2022–2025 (for example, `OT_TOTAL_2022_2025`).

| Code  | Category                                                         |
| ----- | ---------------------------------------------------------------- |
| `GTB` | Grand theft by burglary                                          |
| `OGT` | Other grand theft                                                |
| `TBS` | Theft by snatching                                               |
| `TMT` | Theft of a means of transport for use for a short period of time |
| `OB`  | Other burglary                                                   |
| `OT`  | Other theft                                                      |
| `TPV` | Theft and misappropriation of petty value                        |
| `RBS` | Robbery by snatching                                             |
| `OR`  | Other robbery                                                    |

## Examples

### Parcel layer

```bash
curl -X GET "https://pandora.ask-wire.com/api/gis/?latitude=38.0&longitude=23.7&layer=parcel" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
