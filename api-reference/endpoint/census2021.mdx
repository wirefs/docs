---
title: "Query Census 2021"
description: "Retrieve aggregated Census 2021 data for a building block, identified by geographical code and building block number."
openapi: "GET /api/census2021/{dataset}"
---

## Overview

Returns Census 2021 data for a building block, identified by its geographical code and building block number. Figures are aggregated across every building in the block. For example, `total_buildings` is the number of buildings in the block, and `construction_year_*` fields count buildings per construction period.

The response is a flat JSON object containing every field of the matched record. The exact shape depends on the requested dataset.

<Note>
The query parameter is `geographical_code`, but the response field is named `geographic_code`.
</Note>

Requires a valid Bearer token in the `Authorization` header. See [Authentication](/api-reference/endpoint/authentication) to get one.

---

## Path parameters

| Parameter | Type   | Required | Description                                                                               |
| --------- | ------ | -------- | ----------------------------------------------------------------------------------------- |
| `dataset` | string | Yes      | Census 2021 dataset to query. Currently only `building_and_characteristics` is supported. |

---

## Query parameters

| Parameter           | Type   | Required | Description                                                         |
| ------------------- | ------ | -------- | ------------------------------------------------------------------- |
| `geographical_code` | string | Yes      | Geographical code identifying the area (e.g. quarter/village code). |
| `building_block`    | string | Yes      | Building block number within the geographical area.                 |

---

## Response

Returns a flat JSON object. Every field of the matched Census 2021 record is included. The exact fields depend on the requested dataset.

---

## Example request

```bash
curl -X GET "https://pandora.ask-wire.com/api/census2021/building_and_characteristics?geographical_code=4501000001&building_block=5167" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Error responses

| Status | Description |
| ------ | ----------- |
| `400`  | A required query parameter is missing. |
| `404`  | No record exists for the given dataset, geographical code and building block. |
