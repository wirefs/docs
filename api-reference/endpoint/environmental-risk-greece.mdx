## Overview

Returns one entry per environmental peril (e.g. seismic, flood) for a given coordinate, each with its classification and source provenance.

---

## Request

### Body (application/json)

| Field       | Type   | Required | Description                                                    |
| ----------- | ------ | -------- | ----------------------------------------------------------------- |
| `latitude`  | number | Yes      | Latitude (WGS84).                                                  |
| `longitude` | number | Yes      | Longitude (WGS84).                                                 |
| `perils`    | array  | No       | Perils to return, e.g. `seismic`, `flood`. Omit to return all available perils. |

---

## Response fields

| Field                    | Type   | Description                                             |
| ------------------------- | ------ | ---------------------------------------------------------- |
| `coordinates`              | object | `{ latitude, longitude, crs }` echoing the input location. |
| `risks`                    | array  | One entry per peril.                                        |
| `risks[].peril`            | string | Peril identifier, e.g. `seismic`, `flood`.                  |
| `risks[].category`         | string | Risk classification, e.g. `Zone 2`, `Low`.                  |
| `risks[].score`            | number | Numeric risk score, where available.                        |
| `risks[].scale`            | string | Description of the classification scale used.               |
| `risks[].source.layer`     | string | Source GIS layer identifier.                                 |
| `risks[].source.provider`  | string | Data provider name.                                          |
| `risks[].source.vintage`   | string | Date the source data was published.                          |

---

## Example request

```json
{
  "latitude": 37.9838,
  "longitude": 23.7275,
  "perils": ["seismic", "flood"]
}
```

  "coordinates": { "latitude": 37.9838, "longitude": 23.7275, "crs": "EPSG:4326" },
