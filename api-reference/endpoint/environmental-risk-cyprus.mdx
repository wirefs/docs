## Overview

Returns one entry per environmental peril (e.g. flood, coastal erosion) for a given coordinate, each with its classification and source provenance.

Request and response shapes are identical to
[Environmental risk — Greece](/api-reference/endpoint/environmental-risk-greece); the two are kept as separate endpoints since the underlying hazard models and data sources differ per country.

---

## Request

### Body (application/json)

| Field       | Type   | Required | Description                                                    |
| ----------- | ------ | -------- | ----------------------------------------------------------------- |
| `latitude`  | number | Yes      | Latitude (WGS84).                                                  |
| `longitude` | number | Yes      | Longitude (WGS84).                                                 |
| `perils`    | array  | No       | Perils to return, e.g. `flood`, `coastal_erosion`. Omit to return all available perils. |

---

## Response fields

See [Environmental risk — Greece](/api-reference/endpoint/environmental-risk-greece#response-fields) for the full field reference.

---

## Example request

```json
{
  "latitude": 34.6857,
  "longitude": 33.0357,
  "perils": ["flood", "coastal_erosion"]
}
```
